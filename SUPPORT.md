# Support

Thank you for using Modulex.

## How to get help

- **Bug reports and feature requests**: please open an issue on GitHub at
  <https://github.com/mediusfy/modulex/issues>.
- **Security issues**: please follow the instructions in
  [`SECURITY.md`](./SECURITY.md) instead of opening a public issue.
- **Questions and discussions**: use GitHub Discussions at
  <https://github.com/mediusfy/modulex/discussions> when available, or open an
  issue with the `question` label.

## What to include

When reporting a problem, please include:

- The version of Modulex you are using (`go list -m github.com/mediusfy/modulex`).
- The version of Go (`go version`).
- A minimal code sample or test that reproduces the issue.
- The exact error message or unexpected behavior.

## Response times

This is an open-source project maintained by volunteers. We aim to respond to
issues within a few business days, but cannot guarantee turnaround times.
